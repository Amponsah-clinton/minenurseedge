Question bank: what each number means

These figures are computed from the whole question_bank table (exact counts where possible). They are not filtered by the list search or dropdowns.

Total DB rows
{{ stats_db_total_rows }} — every stored question row (including duplicate General Paper copies per programme).
Mock pool
{{ stats_mock_count }} rows with programme “All Programmes”, used for mock exams. Batch size is {{ mock_question_batch_size }} questions per mock.
Non-mock rows
{{ stats_non_mock_rows }} — rows where programme is not the mock pool (general tests / programme banks). This is a database total. On the list, with All programmes, you see a mix of the newest mock and newest non-mock (half of the load cap each) so mocks do not hide everything else. Choose General tests only (non-mock) in the programme filter to list those rows (up to the load cap).
General Paper (unique)
{{ stats_general_count }} — distinct questions by text; one logical question is stored once per programme, so this is smaller than the row count below.
General Paper (DB rows)
{{ stats_general_paper_rows }} — total rows with paper “General Paper” (typically ≈ unique × number of programmes).
Programme-specific
{{ stats_prog_specific_row_sum }} rows across programmes (papers other than General Paper). The green card “Total unique (bank)” is {{ stats_general_count }} + {{ stats_prog_specific_row_sum }} = {{ stats_unique_total }} (unique General Paper + those rows).
Question list
With All programmes and no search, the table loads up to half of {{ manage_questions_max_fetch }} from non-mock and half from mock (each side newest first), merged by date. With a specific programme filter (including general-tests-only or mock-only), it loads up to {{ manage_questions_max_fetch }} newest rows for that filter. General Paper duplicates are collapsed in the table. Pagination applies only to the loaded set.
