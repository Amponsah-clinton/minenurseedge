Better JSON Bulk Example

You can upload either an array directly or use { "questions": [...] }. Programme is required for specialty papers. For General Paper, leave programme empty or omit it — the question is saved for every programme automatically. Paper title matching is case-insensitive (e.g. general paper works).

      "programme": "Registered General Nursing (RGN)",

        "A": "Liver",
        "B": "Kidney",
        "C": "Spleen"
      },
      "correct_option": "B",
      "explanation": "Kidneys filter blood and form urine."
    },
    {

        "C": "Give oral fluids"
      },
      "correct_option": "B",
      "explanation": "Hand hygiene is critical for infection prevention."
    },
    {
      "programme": "Registered Midwifery (RM)",
